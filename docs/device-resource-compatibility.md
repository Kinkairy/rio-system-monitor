# 屏内存储兼容性实测

2026-10-23，设备为 WinUSB `2A55:9990`、USB revision `0200`、LCD 480×480。本次在用户明确允许覆盖默认动画后进行测试。程序停止实时输出并释放句柄，由单一会话按资源白名单发送命令，没有运行原厂程序。

| 步骤 | 设备返回 | 结论 |
| --- | --- | --- |
| `CD 00 00 00 00 03 …`，tag 1，读 5 字节 | `e001e001ff`；CSW `55534253010000000500000000` | 尺寸为 480×480，tag 1，status 0 |
| `FB D8 00 …`，资源偏移 0，tag 2 | CSW `55534253010000000500000002` | 仍返回 tag 1，status 2；没有确认擦除 |
| GIF 数据写入 `FB D9` | 没有发送 | 首条擦除失败即停止 |
| 播放新资源 | 没有发送 | 未将失败当作成功 |

擦除确认数为 0，写入确认数为 0。此结果表明当前从参考软件还原的资源写入协议尚不适配这台实物，不能据此宣称永久写入成功，也不能通过忽略 tag/status 校验继续。测试后已重新启动主程序，实时帧成功发送且 USB 无错误。完整 USB 应答和默认动画 SHA-256 只保存在本地验证记录，不公开素材或 EXE。

现有参考 EXE 中可以定位 FBD8 擦除、FBD9 写入与 FBDA 配置写入流程，尚未找到可验证的图片资源回读流程。此前只读 SPI/Flash 查询未返回有效文件数据。标准 dpf-ax 提供 Flash 读取 API，但其[Windows 原厂固件读取工具](https://github.com/dreamlayers/dpf-ax/blob/master/tools/readflash_win.py)要求设备以 CD-ROM 方式连接，不能直接当作本机 WinUSB 模式的兼容性证明。

文件预览缓存仅代表本程序最后一次成功写入的记录，不是屏内文件的 USB 回读。尚待完成的是适配本机的资源上传/回读协议、成功播放确认与断电持久播放验收。
