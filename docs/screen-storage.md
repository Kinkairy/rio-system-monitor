# 屏内媒体

屏幕内容和城市选择复用 DialogPopup 组件，均为 280×356。文件弹窗上方使用与城市输入框相同的样式选择文件，中间显示动画预览、文件名及大小，下方是整行“写入”。长文件名末尾显示省略号。首次打开且尚未选择文件时，自动载入内置默认动画预览；只准备预览，不写入屏幕，也不覆盖用户已有选择。恢复图标仍位于设置页“屏幕内容”右侧，与天气刷新图标对齐；恢复确认框随当前语言切换，英文为“Cancel / OK”，中文为“取消 / 确定”。

设置中的“屏幕内容”复用天气长条按钮及同款弹窗，支持 PNG、JPEG、BMP、GIF、WebP/APNG 动画以及 FFmpeg 可解码的 MP4/MOV、AVI、MKV/WebM 等视频。原文件不超过 **3,400,000 字节（3.4 MB，十进制）**。按原比例居中适配 480×480，空余处为黑色，不拉伸或自动裁切。

屏幕使用原生 GIF 资源容器，不是 MP4 解码器。视频在电脑上无声转换为 30 fps GIF；已有 480×480 GIF 原样保留，其他动态图逐帧转换并保留时长。GIF 仅支持调色板颜色，预览显示的是实际转换后的结果。转换后的 GIF 也必须不超过 3.4 MB，超限会明确拒绝并提示剪短，不会偷偷截断视频。长时间或无法解码的转换会中止。转换器包含在本地 EXE 中，无需另装。

选择文件与生成预览不会打开 USB，更不会写入屏幕。用户点击“写入屏幕”才开始替换屏内原有图片/动画，原内容暂不支持 USB 读回备份。先关闭实时帧输出并确认其线程和句柄释放，再由单独资源会话核验 VID/PID、0200 硬件版本与 480×480 尺寸，按资源相对偏移写入。只允许资源窗口 `0x3B6000` 内的 4 KiB 擦除/写入、只读尺寸查询与播放命令。固件、APPLOAD、持久配置及任意地址访问均不开放。

开始写入后保持供电；弹窗禁止关闭，退出请求会等待用户稍后重试。每步严格核验 USB 长度、状态签名、序号、余量及返回值；异常即停止，不自动重试。进度只有在原生播放命令成功应答后到达 100%。

上传后暂停实时监控输出，避免盖住新内容。托盘菜单的“实时监控”通过明确点击重新连接输出。模式自动保存，选择屏内内容模式后程序下次启动不会自动用监控帧覆盖它。失败时保持输出暂停，按提示重接设备再操作。

设置页的恢复图标在明确确认后，触发私有仓库 `fa2f6913e507a728961b18bed42addf9919294f8` 提供的 `RIO-System-Monitor-color-accent-loop.gif` 的预览准备与原生写入。默认 GIF 随本地程序打包，1,022,714 字节、480×480、216 帧、约 7.2 秒；原始素材和默认文件均不进入公开源码仓库。普通启动不会自动刷写默认动画。

资源上传命令来自已保存原软件的静态分析，独立实现，不执行或加载原 EXE/DLL。源码测试使用模拟 USB 检验允许命令、边界、失败停止及互斥；本地视频转换和真实设置弹窗另行验证。**当前尚未对实物执行资源擦写，也未验证断电后的持久播放；完成这些验收前不把协议模拟测试称为硬件通过。** 实时 USB 全帧吞吐此前约 13 fps，30 fps 是渲染/视频转换目标，不保证该物理屏达到 30 fps。
