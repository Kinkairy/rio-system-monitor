# Default record and replacement label

Private assets: Kinkairy/usb-round-screen/artwork/music-mode/default-record.png and record-label.png. Import with --music-art alongside the usual private source, startup-loop and FFmpeg inputs. Public source does not contain the artwork.

Absent, invalid or oversized album images use the complete default record. Valid album covers remain unchanged except that the new 74px RIO center label replaces the plain yellow center circle. The label rotates together with the record. Playback pause freezes rotation; song metadata and lyrics are not replaced merely because artwork is missing.

Tests cover valid, missing and invalid covers, replacing rather than obscuring the label, pause/resume and source-only checkouts without private art. Source-only checkouts use a neutral substitute, not the approved proprietary artwork. No deployment is performed.
